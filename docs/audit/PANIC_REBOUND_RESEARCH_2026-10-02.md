# Panic rebound 策略研究记录（2026-10-02）

起因：复盘最近两笔买入（ONE-USDT 2026-09-23、G-USDT 2026-09-20）的入场时机，进而验证当前 panic rebound 策略的收益、回撤、容量、尾部风险和参数稳健性。

数据：`~/Downloads/stocks/ex_okx/data`（274 个 OKX USDT 现货，含 109 个已下架币；1D/1H，2022-04 → 2026-09），另从 OKX 拉取 103 个可交易日的 1m 数据。脚本与缓存在 `~/Downloads/stocks/ex_okx/research/panic_rebound_2026-10/`（脚本内路径指向当时的临时目录，复跑前需改路径）。

## 结论摘要

1. 策略 edge 真实存在，但 2025 年起大幅衰减：样本外（2025-01 → 2026-09）约 +40%/年（小时级、偏乐观），训练期约 +157%/年。
2. 不改策略参数，不加止损 / 止盈 / 拉盘过滤 / 分散仓位 —— 数据显示都不改善风险收益。
3. 容量很小：2025–26 年只在约 500 – 几千 USDT 规模有效，5 万 USDT 时年化只剩个位数。
4. 真正风险是"单日暴跌不反弹"：历史最坏盘中浮亏 −73%（ACT 2025-10-11），收盘反弹到 +0.1% 是运气。风控只能靠策略账户的资金上限（按"单日亏 75% 可承受"来定）。
5. 唯一值得改的是执行：买单价格需按 OKX 价格带（`buyLmt`）钳制（见第 7 节）。

## 2. 拉盘过滤（run7 = 开盘 / 7 天前收盘）—— 不采用

- 事件级（每个 0.72× 触发单独看，孤立暴跌日 ≤3 币）：run7<1.5 平均 +6.9%（胜率 77%），run7≥1.5 平均 −3.2%（49%）；跨买入深度、退出方式、年份、剔除单币都稳健（bootstrap p<0.001）。
- 但账户级模拟（一个资金池、跳过前两名）中，策略几乎只在全市场暴跌日交易，过滤会剔除赢单：2023 +261%→+181%，2024 +321%→+231%，回撤不变。
- 结论：事件级有效不等于账户级有效，不加。

## 6. 局限

- 成交模型偏乐观：按整分钟成交额（含限价以上的成交）的比例、恰好以 0.72× 成交；未模拟 ask ≤ limit 检查。
- 1281 个计数币（主要是下架币）无分钟数据，排名仍有部分随机；349/804 个买入候选是下架币，只能用小时数据。
- 交易天数少（约 35 笔），收益集中在少数暴跌日（2022-05-14 一天 11 笔成交）。
- 当前参数 2026-09 才设计，可能见过 2025 数据，不是严格样本外。

## 7. 优化方案

1. 策略规则：不改。
2. 资金：策略账户 ≤ 约 5,000 USDT，且金额以"单日亏 75% 可承受"为上限；当前约 500 USDT 在两条线内。
3. 执行：按 OKX 价格带钳制买入价。证据：2026-09-23 ONE 连续 91 次 `BUY_NOT_CREATED`，原因 "The highest price limit for the buy leg is 0.004566"，而限价为 0.004581。修正：`px = min(0.72× 限价, buyLmt)` 向下取 tick；若 ask 高于钳制后价格则以 `ASK_ABOVE_PRICE_BAND` 跳过；价格带读取失败时退回原限价（等同现状）。回测无法量化该修正效果（无历史价格带数据）。
4. 持续验证：每周把实盘交易与回测预测对比，每个新暴跌日都是新的样本外点。

## 8. 资金费率（funding）作为开仓过滤 —— 不采用

本地历史没有覆盖山寨币的 funding（只有 10 个主流币 + OKB，或最近 3 个月），OKX 公共 API 也只给 3 个月，因此用 Binance 永续 funding 作代理（2022 起），换算为每 8h 费率，取入场前 24h 均值。963 个事件中 640 个有 Binance 永续。

- 事件级有弱相关，但方向与"负 funding = 逼空反弹"的直觉相反：24h funding ≤ −0.10%/8h 的事件平均 −1.5%（n=18，p10 −32%），> +0.01% 的平均 +16%；Spearman 全部 +0.12（p=0.002），孤立暴跌日 +0.29（p=0.016，n=67）。
- 账户级无效：实际成交的约 48 笔里没有一笔 24h funding ≤ −0.10%，过滤 ≤ −0.10% 与现状完全相同；过滤 ≤ −0.03% 收益 +311%→+317%（噪声级）；过滤 < 0 反而降低（+458%→+447%）。
- 约一半实际成交的币没有 Binance 永续，过滤无法覆盖。
- ACT 2025-10-11（−73% 浮亏）入场前 funding +0.004%，funding 不会预警最大的尾部风险。

## 9. 入场时段与 funding 结算时点 —— 不采用

按 0.72× 触及的小时（UTC+8）和距上次 funding 结算的时间分组（事件级，小时精度）。

- 距结算时间：表面差异（结算后 1–3h 平均 +17.7%）81% 来自 2025-02-03 一天，只有 8 个不同日期；按日平均只有 +3.8%，反而低于 3–7h 的 +9.3%。暴跌触及集中在结算后 4–5h（58%），同样是 2025-10-11 等少数全市场日造成。无可用信号。
- 时段：08–12h 的 +16.6% 有 88% 来自 2025-02-03。唯一稳健的是孤立暴跌日 00–04h 触及：平均 −6.8%（31 个不同日期，去掉最大一天 −8.1%），对比 12–16h +8.1%。
- 但账户级过滤反而有害：跳过 02:00 前的买入 +458%→+425%，跳过 04:00 前 +458%→+390%；被剔除的是 BIGTIME、TRB、PEPE 等赢单。账户实际成交的早盘单都在多币同时暴跌的日子，不是孤立暴跌。
